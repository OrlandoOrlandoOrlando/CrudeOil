## Guide
### Git Codespaces
Codespaces offer a way to edit code in the browser. Skip to <a href="#git-part-1">Git Part 1</a> if you want to code on your machine.
1. Go to the <a href="https://github.com/OrlandoOrlandoOrlando/CrudeOil.git">Github page</a>
1. Click on `Code <>`, switch to the `Codespaces` tab, and click on `Create codespace on master`
### Git Part 1
1. Get the latest version of <a href="https://git-scm.com">Git</a>
1. `git clone https://github.com/OrlandoOrlandoOrlando/CrudeOil.git ~/CrudeOil`
1. Navigate to your copy of the repo `cd CrudeOil`
### Python
1. Get the latest version of <a href="https://www.python.org">Python</a>
1. Create a virtual environment `python -m venv .venv`
1. Activate the virtual environment `source .venv/bin/activate`
1. Install the requirements.txt `pip install -r requirements.txt`
1. Run `./main.py`
